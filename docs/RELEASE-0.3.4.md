# Pliego 0.3.4 — castellano de España

Una versión pequeña de acabado. Pliego funciona igual que en la 0.3.3.

## Cambios

- Los textos de la aplicación hablan de tú, en castellano de España, igual que el README. Antes mezclaban el voseo de la aplicación con el tú de la documentación.
- El menú **Ver** usa los mismos nombres que los botones: **Leer**, **Ambas** y **Editar**.
- El README explica qué hacer si Windows SmartScreen avisa al abrir el ejecutable, que todavía no tiene firma digital: **Más información** y después **Ejecutar de todas formas**.
- El README estrena portada.

## Descarga

Descarga **Pliego-0.3.4-win32-x64.zip**, descomprime la carpeta completa y abre **Pliego.exe**. No necesitas Node.js. El archivo **SHA256SUMS.txt** permite comprobar que la descarga es idéntica a la publicada.

Si tienes instalada la 0.3.3 con **Install-Pliego.ps1**, cierra Pliego y vuelve a ejecutar el instalador de esta versión. Se conservan los documentos y los datos de lectura locales.
