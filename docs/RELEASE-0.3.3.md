# Pliego 0.3.3 — primera versión pública

Pliego permite leer dos documentos en una misma ventana, con desplazamiento, búsqueda y controles independientes. Funciona en Windows x64, en local y sin cuenta.

## Descarga

Descarga **Pliego-0.3.3-win32-x64.zip**, descomprime la carpeta completa y abre **Pliego.exe**. No necesitas Node.js para utilizarlo. El ZIP incluye un instalador opcional para crear una instalación estable por usuario y accesos directos.

**Dos textos**, junto a **Abrir**, permite elegir el segundo archivo. En PDF, el mismo botón se llama **Dos PDF**.

## Incluye

- Lectura y edición de Markdown con guardado independiente de cada panel.
- Lectura de PDF, Word (`.docx`) y texto plano.
- Búsqueda, biblioteca local, favoritos y recientes.
- Cuaderno local de notas, marcadores y resaltados de PDF, con exportación a Markdown.
- Copias anteriores al guardar y protección frente a cambios externos.
- Código fuente bajo licencia MIT y avisos de las bibliotecas utilizadas.

## Alcance

Primera distribución pública para Windows x64. El ejecutable no tiene firma digital. Solo Markdown se edita; Word se muestra en lectura y puede cambiar su paginación. No incluye OCR, PDF con contraseña, comparación automática de diferencias ni sincronización.

Las comprobaciones de esta versión se realizaron en Windows con una instalación nueva de las dependencias, documentos sintéticos y perfiles aislados. Cubren lectura, edición, dos paneles, guardado, PDF, biblioteca y el instalador opcional; no constituyen una prueba en todos los equipos Windows.

Las incidencias y propuestas se pueden enviar desde la pestaña **Issues** del repositorio, utilizando ejemplos sin datos personales.
