# Un lugar para leer

Un texto necesita espacio. A veces lo encontramos en una mesa despejada; otras, en una ventana que deja de pedirnos cosas.

## La primera lectura

Leo para descubrir qué dice una página. Vuelvo a leer para descubrir qué había pasado por alto.

Comparar dos versiones ayuda a ver el movimiento: una frase que respira, un párrafo que encuentra su sitio, una palabra que ya no hace falta.

## Una idea abierta

Corregir también es leer. Cada cambio propone una forma distinta de prestar atención.

Este documento es un ejemplo creado para mostrar Pliego.
